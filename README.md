# Hunian Real Estate — Architectural Scrollytelling Experience

A premium real estate showcase web application featuring interactive canvas scroll-driven animations, Lenis smooth scrolling, architectural property showcases, and interactive inquiry modals.

## ✨ Features

- **Architectural Frame-by-Frame Scrubbing**: 3D home exterior & interior animation rendered frame-by-frame on canvas tied directly to scroll progression.
- **Lenis Smooth Scroll Engine**: Fluid inertial scrolling for an editorial architectural feel.
- **Minimalist Modern Design**: Clean typography (Plus Jakarta Sans) with contemporary layout aesthetics.
- **Property Inquiries & Search**: Integrated property discovery filters and consultation triggers.

## 🛠️ Tech Stack

- **Vite** — Fast, modern frontend build tool
- **HTML5 & Vanilla CSS** — Custom minimalist real-estate UI
- **JavaScript (ES Modules)** — High-performance requestAnimationFrame canvas rendering
- **Lenis** — Modern smooth scroll library

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/am-523/hunian.git
cd hunian
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
